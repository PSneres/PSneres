## Featured Projects

### [Library API](https://github.com/PSneres/library-api)

A RESTful API for library management, handling books, members, loans, returns, and inventory availability.

- Layered architecture with controllers, services, and repositories.
- PostgreSQL transactions and row-level locking to maintain data consistency during concurrent operations.
- JWT authentication, input validation, rate limiting, and structured logging.
- Integration testing with Jest and Supertest.

`JavaScript` · `Node.js` · `Express` · `PostgreSQL`

[View source code and documentation →](https://github.com/PSneres/library-api)

### [Discord Bot TS](https://github.com/PSneres/discord-bot-ts)

A multipurpose Discord bot featuring moderation tools, a virtual economy, an experience (XP) system, and per-server settings.

- Modular command and event architecture with dynamic loading.
- Abstract classes, interfaces, and generics in TypeScript.
- MongoDB persistence with a clear separation between business logic and data access.

`TypeScript` · `Node.js` · `Discord.js` · `MongoDB`

[View source code and documentation →](https://github.com/PSneres/discord-bot-ts)
